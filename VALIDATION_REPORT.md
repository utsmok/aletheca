# OpenAlex API Validation Report

Generated by comparing aletheca models and filter params against live API responses (10 samples per entity) and official OpenAlex documentation.

## Model Fields

### Fields Missing from Models (present in live API)

**All entities:**
- `created_date: str` — ISO datetime string
- `updated_date: str` — ISO datetime string
- `works_api_url: str` — URL for works filtered by this entity

**Most entities:**
- `summary_stats: SummaryStats` — h_index, i10_index, 2yr_mean_citedness (present on: Author, Source, Institution, Publisher, Funder)

**Work:**
- `content_urls: dict` — PDF and XML content URLs

**Author:**
- `block_key: str` — internal block key
- `full_name: str` — "LAST, First" format name
- `raw_author_names: list[str]` — raw name strings

**Funder:**
- `awards_count: int` — number of awards (NOT `grants_count` which doesn't exist)

**Institution:**
- `status: str` — entity status

**Keyword:**
- No additional fields (only the common created_date, updated_date, works_api_url)

## Filter Params

### Critical Issue: Dot Notation

OpenAlex uses **dot notation** in filter strings, not underscores:
- ✅ `authorships.author.id` NOT ❌ `authorships_author_id`
- ✅ `last_known_institutions.id` (plural!) NOT ❌ `last_known_institution_id`
- ✅ `affiliations.institution.id` NOT ❌ `affiliation_institution_id`
- ✅ `primary_location.source.id` NOT ❌ `primary_location_source_id`
